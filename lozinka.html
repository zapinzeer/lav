Nova lozinkaNew password

Lozinka za pravljenje kvizova ne stoji u kodu kao tekst, nego kao otisak (SHA-256) u datoteci config.js. Ovde izračunaš otisak za novu lozinku. Sve se računa u tvom pregledaču i ništa se ne šalje.

The password for creating quizzes is not stored in the code as text, but as a fingerprint (SHA-256) in the file config.js. Here you calculate the fingerprint for a new password. Everything is calculated in your browser and nothing is sent anywhere.

Tvoj otisakYour fingerprint

  1. Otvori config.js u repozitorijumu na GitHub-u i klikni na olovku (Edit).
  2. Zameni vrednost posle creatorPasswordHash: otiskom iznad (između navodnika).
  3. Klikni Commit changes. Posle minut-dva nova lozinka važi.
  1. Open config.js in the repository on GitHub and click the pencil (Edit).
  2. Replace the value after creatorPasswordHash: with the fingerprint above (between the quotes).
  3. Click Commit changes. After a minute or two the new password is valid.

Ovaj pregledač ne podržava računanje otiska na ovoj adresi. Otvori stranicu preko https adrese.This browser does not support calculating the fingerprint at this address. Open the page over an https address.
